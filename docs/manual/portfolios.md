# Portfolios and projects

The dashboard separates organisational portfolios from technical projects and project-to-project relationships.

Select **New portfolio** to create a portfolio together with its required first project. Enter a portfolio name and description, then the first project name, description, and SQL dialect. Both records are created together; an incomplete portfolio is never left behind.

Select a portfolio button on the dashboard to see its projects. **All projects** shows the entire catalogue, while **Unassigned** shows projects that are not yet organised. Each project card has a **Move to** control for explicit reassignment.

Select **New project** to create another project. Choose its portfolio immediately or leave it unassigned. The System map remains the place for technical relationships such as dependencies and integrations; those links are separate from portfolio membership.
